CafeSnap visual booking guide - screenshot drop folder
======================================================

The guide page /guides/how-cafesnap-books-for-you references the
images below. They are intentionally NOT committed as binaries yet:
the founder reviews the page first, then drops real screenshots in
here with these exact filenames. Until a file exists the page shows
a labelled "screenshot to be added" placeholder, so the page is safe
to ship without the images.

Required files (see the shot list in the PR description):

  step1-home.png        cafesnapbot.com homepage, first view
  step2-details.png     Step 1 of the booking form (cafe + party size)
  step3-dates.png       Step 2 of the booking form (date picker, up to 3)
  step4-time.png        Step 3 of the booking form (time preference)
  step5-stripe.png      Stripe Checkout hosted page (card entry)
  step6-working.png     Status page while the bot is searching
  step8-status.png      Status page after a booking is secured
  step9-cancel.png      The cancel / release screen

Recommended width 1080px, PNG, mobile-screenshot friendly. The page
is responsive and will scale them down.
